# Battlegrounds Open · 14.5.0

**简体中文** | [English](README.en.md)

非官方战棋玩法实现，使用 Godot 4.7。此目录是可导入运行的源码工程，包含游戏代码、必要功能数据、资源接口和项目自制的占位图、界面与特效。

## Windows 玩家下载

下载 [v14.5.0-r2 Windows x64 发布包](https://github.com/ctyyytc/battlegrounds-open/releases/tag/v14.5.0-r2)，完整解压后双击 `battlegrounds-open.exe`；保留同目录 `.pck`。无需安装 Godot。发布包不含资源包，资源包另行准备，通过游戏内“资源包”菜单安装或卸载。

此发布版已在 Windows 上实际操作验证：A包安装/重启保持、买入打出与手动保存、不同进程读档续作、卸载保留来源与存档、重装恢复旧档，以及最终ZIP解压后的无包开局和跨进程存读。数值不匹配时拒读旧档属于兼容保护。未完成其它硬件、完整自然局或全组合验收。

r2 为14.5.0的发布修订：修复导出程序内置图像的加载，使关键词特效及尤格命运之轮正常显示；源码补齐当前界面的53个可编辑SVG。游戏版本仍为14.5.0。

r2 补测了205个实际使用的特效帧、9个转盘图像，以及饰品第6/9回合闪烁、购买后停止、减少动态下静态显示。最终ZIP的正式程序验证了代表性关键词画面、转盘、手动保存和新进程读档；导出PCK的生产接口另测A包安装/卸载/重装与跨进程存读，922张图片的哈希及解码全部通过。场景使用隔离构造的测试存档，未重跑完整自然局或全组合。

## 源码启动

1. 安装 Godot 4.7；本次源码冒烟使用 4.7.2 stable。
2. 用 Godot 导入本目录的 `project.godot`，等待首次资源导入完成，运行主场景。无需开发插件。
3. 首页“开始游戏”支持全英雄手选和英雄三选一；“资源包”可从工程外安装本地资源包。不安装资源包也可使用默认占位内容开局。

命令行也可先运行 `godot --editor --path . --import`，然后运行 `godot --path .`。Windows 可用对应的 Godot 控制台可执行文件。

无资源包时显示兼容 ID 和通用计算说明，采用中性基础数值：英雄30生命/0护甲、普通随从1/1、明确定义的金色随从2/2、酒馆法术和大小饰品2币；规则、资格与效果由代码定义。这是默认占位模式，不声称还原原版图文或数值。

## 资源包与存档

资源包不放在本目录。解压单独提供的包，在主菜单“资源包”→“安装资源包…”选择其 `pack.json`，安装成功立即更新。“卸载并恢复默认”只移除应用管理的安装副本，保留来源包与对局存档。格式、路径要求和离线工具见 [RESOURCE_PACKS.md](RESOURCE_PACKS.md)。

应用使用独立的 `battlegrounds-open` 用户目录，与开发工程分开。游戏存档和已安装资源包写入 Godot 的用户数据位置，不写入源码目录。每轮开始的强制选择完成后自动保存一次，中途可手动保存；数值不同的资源包会阻止读取不匹配的对局档。文字和图片变更不改变数值身份。

设置不会自动暂停对局；招募计时和回放按当前状态继续。招募中可撤销最近3个完整操作，使用次数不限；不能跨回合、战斗或读档。
